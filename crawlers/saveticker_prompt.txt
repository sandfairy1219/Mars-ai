아래는 SaveTicker "오선" 작성자의 미국 증시 요약 또는 SAVE 주간 리포트 원문입니다. JSON 형태로 제공됩니다.

스크립트 출력의 "type" 필드를 먼저 확인하세요:

## type = "daily" 인 경우 (일일 미국 증시 요약):
1. 아래 구조화된 형식으로 요약해주세요. 한국어(반말)로 작성.

형식:
```
📊 **【미국 증시 요약 ｜YYYY년 MM월 DD일 (요일)】**

🟡/🟢/🔴 **시장 요약** — S&P500 +-X.XX%, 다우 +-X.XX%, 나스닥100 +-X.XX% (핵심 테마 한줄)

🟢/🔴 **첫번째 핵심 주제** — 주요 내용 (구체적 수치 포함)

🟢/🔴 **두번째 핵심 주제** — 주요 내용 (구체적 수치 포함)

💻 **업종별 움직임** — 주요 업종/종목 등락 (구체적 수치)

🛢️ **원자재/환율** — WTI $XX.XX, 금 $X,XXX, 달러 인덱스 XXX.XXX, 국채 10년 X.XXX%

🗣️ 주요 인사 발언 한줄 요약 (있을 경우만)

📅 오늘의 주요 일정 (있을 경우만)

🔗 [원문 보기](URL)
```

2. 각 섹션에 적절한 이모지 사용:
   - 🟢 = 긍정/상승
   - 🔴 = 부정/하락
   - 🟡 = 혼조/중립
   - 💻 = 기술주/업종
   - 🏦 = 금융/실적
   - 🛢️ = 에너지/원자재
   - 🗣️ = 인사 발언
   - 📅 = 일정
   - 📊 = 헤더

3. 응답 마지막에 **반드시** images 배열에 있는 각 파일을 `MEDIA:/tmp/saveticker_img_*.png` 형태로 그대로 포함시켜 주세요. 이미지가 여러 개면 각각 MEDIA: 줄을 별도로 넣으세요. images 배열이 비어있으면 MEDIA는 생략.

4. (state 마킹은 래퍼 스크립트가 자동으로 처리합니다. **출력에 명령어·코드블록·설명을 쓰지 마세요.** 요약문만 출력하세요.)

## type = "weekly" 인 경우 (SAVE 주간 리포트):
1. 주간 리포트는 **이미지 중심** 자료입니다 (텍스트는 비어있거나 최소). 아래 형식으로 소개하세요:
```
📊 **【SAVE 주간 리포트 ｜YYYY.MM.DD — MM.DD】**

🟢/🟡/🔴 **주간 요약** — 지난주 시장 핵심 흐름 2-3줄

📈 **핵심 차트** — 아래 이미지들이 지난주 증시·업종·지표 차트입니다

🔗 [원문 보기](URL)
```
2. images 배열이 있으면 **이미지를 분석/확인하지 말고** 최대 10장을 `MEDIA:/tmp/saveticker_img_*.png` 형태로 그대로 포함시켜 주세요 (이미지 파일 경로만 그대로 쓰면 됨). 이미지가 10장 이하면 전부 포함.
3. (state 마킹은 래퍼 스크립트가 자동 처리 — 명령어·설명 출력 금지. 요약문만 출력.)

## 공통
- 출력에는 **명령어, 코드블록, 안내문, 메타설명을 절대 넣지 마세요.** 채널에 그대로 게시되는 요약문만 출력합니다.
- 스크립트 출력이 "NO_NEW_POSTS"면 아무것도 쓰지 말고 빈 응답을 주세요 (이미 전송한 글이라는 뜻).
- 원문 출처 링크도 반드시 포함: `🔗 [원문 보기](url)`
